## 元の本文

関連：#59（ライブテストを `tests/live/` へ移動）

## 現象

`scripts/test-live-api.sh` の最後の行は、次のとおりです（2026-10-28 の `develop`、`2876207`）。

```shell
python -m pytest -m live_api tests/integration/test_live_api.py
```

ライブテストは #59 で `tests/live/test_live_api.py` へ移したので、このパスにはファイルがありません。環境変数の確認を通ったあとの pytest は、`ERROR: file or directory not found: tests/integration/test_live_api.py` で終わります（exit 4、テストは0件）。APIは呼ばれないので費用は発生しませんが、スクリプトでライブテストを実行できません。

確かめ方：`--collect-only` で同じパスを渡すと、上のエラーで exit 4 になります（APIは呼びません）。

```shell
python -m pytest --collect-only -q -m live_api tests/integration/test_live_api.py
```

## やること

- パスを `tests/live/test_live_api.py` に直します。`src/sheltersim/llm/config.py` のAPIキーのゲートは、`tests/live/test_live_api.py::test_live_` のテストにだけ開くので、ほかのパスにはしません。
- 直したあとの確認は `--collect-only` で行い、ライブテストそのものは実行しません。ライブテストの実行には、`docs/llm-integration.md` のとおり、その時点のオーナー承認と予算が要ります。
- スクリプトの存在と使い方は、`docs/llm-integration.md` の「利用記録とlive連携test」にも `docs/testing.md` にも書かれていません。使い方を書き足すか、スクリプトを残す必要があるかを決めます。

## 範囲外

- ライブテストの中身、予算、ゲートの条件を変えること。

## 完了の条件

- `scripts/test-live-api.sh` が `tests/live/test_live_api.py` を対象にしている。
- 環境変数を設定した状態で `--collect-only` にしたときに、ライブテストが収集される（実際のAPI呼び出しはしない）。
