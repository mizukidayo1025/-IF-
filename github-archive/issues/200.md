## 元の本文

## 何が起きるか

図面の候補抽出（Project画面の「候補抽出」、`operation: "extract"`）で、外壁に接する部屋が部屋（Zone）の候補になりません。壁の候補は出ます。

合成の図面（400×300px、外壁の長方形を太さ4pxで描く）で確かめました。

| 図面 | 部屋の候補 |
|---|---|
| 部屋1つ（外壁だけ） | 0件 |
| 外壁＋端から端までの仕切り1本（部屋2つ） | 0件 |
| 外壁＋仕切り2本（部屋3つ） | 中央の1件だけ |

ふつうの平面図では多くの部屋が外壁に接するので、部屋の候補がほとんど出ません。

## 原因

`region/plan_extract.py`の`_rectangular_room_candidates`は、上下の横の壁の両方にかかる縦の壁を部屋の左右の境界として数えます。そのときの条件が`overlap_left + 6 <= x <= overlap_right - 6`で、縦の壁が横の壁の端から6px以上**内側**にあることを求めています。外壁の角では縦の壁と横の壁が同じ位置で接するので、外壁の縦の壁は必ず除外されます。誤差の許容は、端の外側に向けて`overlap_left - 6 <= x <= overlap_right + 6`とするのが意図だと考えています。

## 確かめ方

`tests/unit/region/test_plan_extract.py`に`xfail`（strict）で置きます。

#178 の「図面の取り込み」で見つけました。

### 2026-10-28T13:54:56Z — WaTeR-7

元コメント: https://github.com/jphacks/tkb_2615/issues/200#issuecomment-6470889656 / 更新: 2026-10-28T13:54:56Z

#207 で修正しました。縦の壁を部屋の左右の境界として数える条件を、横の壁の端の外側へ6pxまで許す形に直しました（上下方向と同じ向き）。合成の図面で、部屋1つ・2つ・3つの図面がそれぞれ1件・2件・3件の部屋の候補になることを確かめ、`tests/unit/region/test_plan_extract.py` の `xfail` を外しました。仕切りに扉がある図面では、建物全体が1つの部屋の候補になります（確認待ちの候補なので、図面を描く人が除外か修正をします）。
