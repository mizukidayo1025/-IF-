## 元の本文

有効な介入で Run が止まります。`main`（32a28b4）の `src` で再現しました。Rust 移植の確認用の Scenario を作るときに見つけました。修正はしていません。

## 再現
`set_staff_availability` に `end_minute` と guard の両方を付けて実行すると、次のエラーで止まります。

```
only a start event may store a guard
```

## 原因
`events/handlers.py` の `StaffUnavailabilityHandler` は、復帰イベントに `effect_program_v1` を写すとき、`phase` を `derived` にしますが guard を残します。

## 確認の扱い
`feature/rust-port` の全経路の確認（`benchmarks/gate_scenarios.py`）では、今の結果として `known_stops` に固定してあります。直すと期待値が変わるので気づけます。
