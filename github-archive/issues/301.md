## 再現
生成 Scenario の全員の `stress_sensitivity` を `0.0` にして `run_scenario` を実行すると（`SHELTERSIM_NATIVE=0`）、次のエラーで止まります。

```
policies/social.py  eligible_contributions = {
ValueError: zip() argument 2 is shorter than argument 1
```

`stress_sensitivity` は `experiments/scenario.py` で `ge=0.0` なので、0 は有効な値です。

## 原因
`ExpressivenessChannelOpennessPolicy.update`（`policies/social.py`）で、次の順に起きます。

1. `eligible` に接触があっても、重みの合計 `weight_total` が 0 だと `if weight_total > 0.0:` の中に入らず、`pair_shifts` は空のままです。
2. その後の `zip(eligible, pair_shifts, strict=True)` で、長さが合わず `ValueError` になります。

コードを読む限り、重みはすべて `expressiveness * channel_strength * stress_sensitivity` なので、送り手の `source_expressiveness_by_agent` や、接触の種類の channel strength が 0 の場合にも同じことが起きるはずです（この2つは実行していません）。

## 判断してほしいこと
- 重みの合計が 0 の人は「伝播なし」として続けるのが意図でしょうか。それとも、このような入力を Scenario の検証で拒否すべきでしょうか。
