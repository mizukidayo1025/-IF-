## 起きること

UIで作ったScenario（生成Scenario）で、行動Policyだけを変えた2つのRunを `sheltersim compare --behavior-policy-comparison`（`compare_run_artifacts(..., allow_behavior_policy_change=True)`）で比べると、必ず次のエラーで拒否されます。

```
ValueError: policy comparison inputs differ beyond the declared behavior policy
```

`fixtures/scenarios/h00_small_replay.json` のような、モデル一式（suite）を使わないScenarioでは比べられます。

## 再現

```python
base = <共通fixture generated_scenario（duration_days を短くしたもの）>
candidate = base.with_behavior_policy_variant("priority-rule-v1")
run_scenario(base, out_b, trace_level=TraceLevel.FULL)
run_scenario(candidate, out_c, trace_level=TraceLevel.FULL)
compare_run_artifacts(out_b, out_c, allow_behavior_policy_change=True)  # ValueError
```

`sleep-aware-utility-softmax-v2` から `utility-softmax-v1` に変えた場合も同じです。

## 原因

2つのRunのマニフェストで、比較側（`experiments/comparison.py` の `_validate_behavior_policy_pair` の `normalized_inputs`）が読み替えない違いは、次の2つだけでした。

| 項目 | 基準（生成Scenario） | Policyを変えた側 |
|---|---|---|
| `model_configs.policy_registry` | `suite_id: core-model-suite-v2`、`schema_version: 3` | `suite_id` なし、`schema_version: 2`。ほかの領域のモデルは、suiteと同じものが個別に並ぶ |
| `model_configs.behavior.sleep_debt_utility_weight` | `1.0` | なし |

生成Scenarioは、モデル一式 `core-model-suite-v2` で行動Policy（`sleep-aware-utility-softmax-v2`）を選びます。`ScenarioSpec.with_behavior_policy_variant` は、suiteが固定する行動Policyと違うものを選ぶと、suiteを個別の指定に展開します（`experiments/scenario.py`）。また、v2専用の `sleep_debt_utility_weight` を取り除きます。一方、比較側は `behavior.policy` と `source_id` しか読み替えません。そのため、行動以外のモデルが同じでも「入力が違う」と判定されます。

`model_assumptions.behavior` の違い（variant、policy_version、selection_rule、capabilities、source_id）は、比較側が読み替えているので問題になりません。

## 期待すること

生成Scenarioと、その `with_behavior_policy_variant` の結果を比べられること。このとき、行動以外の入力が実際に違えば、今までどおり拒否すること。

直し方の候補は次の2つです。
- 比較側で、`policy_registry` をsuiteから個別の指定に展開してから比べる。`behavior` 領域を除く。あわせて、Policy専用の設定（`sleep_debt_utility_weight`）を読み替える。
- 差し替え側で、表現を変えずに済む形にする。

どちらの場合も、モデルの係数は変えません。

## テスト

`tests/e2e/test_policy_comparison.py` に、生成Scenarioで期待する形のテストを `xfail(strict=True, raises=ValueError)` とこのIssue番号を付けて置きます（#137 のPR）。直したら印を外します。
