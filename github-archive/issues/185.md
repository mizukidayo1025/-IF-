## 起きること

1つの EffectProgram に、同じ人について次の2つの効果を書くとします。

- 10分：`population_presence`（`action: temporary_exit`）
- 40分：`population_presence`（`action: return`）

すると、計画の段階で拒否されます。

```
EffectProgram could not be scheduled: effect 'back' return target must be a retained absent person
```

## 原因

計画の検査（`events/effects.py` の `validate_effect_program`）は、分岐した時点の状態だけを見て、各効果を確かめます。帰還の対象は「すでに不在の人」でなければならないため、同じ介入の中で先に一時外出することを考えずに拒否します。

`expected_return_minute`（帰る予定の時刻）を指定しても、自動では帰還しません（予定を記録するだけ）。そのため、「一時外出して40分に戻る」には、外出の介入と、40分に分岐した帰還の介入の2つが要ります。LLMのコンパイラーが、文から外出と帰還の両方を1つの介入として作った場合も、拒否されます。

## 期待すること

同じ介入の中で、先に一時外出する人への帰還を受け付けること。次のどちらかが考えられます。

- 計画の検査で、同じ介入の中の先の効果による在所の変化を見積もる。対象を一時外出と帰還の組み合わせに絞れば、範囲は小さい。
- `expected_return_minute` の時刻に、帰還を予定に入れる（外出の指示だけで、戻りまで表せるようにする）。

なお、#181 で、一時外出は手が空くまで延期されるようになりました。そのため、外出が帰る予定の時刻より遅れる場合（その場合は外出を取りやめる）との関係も、あわせて決める必要があります。係数は変えません。
