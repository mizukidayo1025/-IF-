```
StateInvariantError: shared_operations_v1 care status disagrees with the persisted support request
```

- 効果の処理（`events/effects.py` の `MutableWorldState.from_dict(world.to_dict())`）は、まとまりの途中で完全な検証を呼びます。

他の「写して差し替える」効果の処理でも同じことが起きる可能性がありますが、確かめていません。
