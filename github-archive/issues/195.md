## 起きること

EffectProgram の環境の変更（`set_ambient_noise` など）に guard と終了時刻を付けたとします。開始の時刻に guard が偽だと、開始のイベントは正しく「抑制（suppressed）」になります。しかし、終了時刻の期限切れのイベント（`effect_program_environment_expire`）は「失敗（failed）」として記録されます。

```
zone environment modifier is invalid: zone environment modifier is not active
```

シミュレーションは止まりません。ただ、正しく動いた結果（条件を満たさなかったので何もしなかった）なのに、介入が失敗したという記録が残ります。

同じ状況で、ほかの操作の期限切れは「抑制」になります。

| 操作 | 期限切れのイベントの結果 |
|---|---|
| `set_facility_availability` | suppressed（`facility availability modifier is not active`） |
| `add_temporary_space` | suppressed（`temporary-space effect did not start or does not match its expiry`） |
| `set_route_access` | suppressed（`geometry modifier was not applied or already expired`） |
| `set_ambient_noise` | **failed** |

## 再現

生成Scenario（60分）の本線を10分まで進め、10分で分岐します。`set_ambient_noise`（対象 `sleeping`、`level: 0.8`、`end_minute: 40`、guard `zone.occupancy gt 1000`）を入れて60分まで進めます。

## 期待すること

開始が guard で抑制された環境の変更の期限切れは、ほかの操作と同じく「抑制」として記録すること。係数は変えません。
