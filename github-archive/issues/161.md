## 起きること

保存したRunの inspector（`web/inspector.py` の `zone_map`）は、どのRunにも同梱の体育館の配置（`gym_synthetic.json`）を使います。生成Scenarioを CLI で実行したRunでは、次のことが起きます。

- 体育館の配置にない区画（`food`、`intake`、`medical`、`quiet`、`staff`）に多角形がつかない。
- その区画にいる人が、知らせなしに地図から外れる。
- 体育館にしかない区画（`water_station` など）が、`modelled: False` として描かれる。

## 再現

1. `generated_previews(duration_days=1/48)` の Scenario を、`run_scenario(..., trace_level=FULL)` で `runs/gen` に出力する。
2. `InspectorService(runs).zone_map("gen", at_minute=20)` を呼ぶ。

`agents` は20人中17人になり、`food`（2人）と `staff`（1人）の区画は `polygon` が None になります。

## 影響

Project画面のRunは frame（図面つき）で描くので、影響を受けません。CLI で生成Scenarioを実行し、inspector で見る場合だけです。

## 期待すること

次のどちらかにすること。

- 図面のあるRunでは、図面から描く。
- 描けない区画と人がいることを、地図に明示する。
