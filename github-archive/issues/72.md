## 元の本文

## 現象

職員の担当（技能）を変える介入（`set_staff_role`）をBranchに適用すると、例外で止まります。検証は通りますが、予定を作る段階で失敗し、利用者には「適用できない理由」が返りません。

```
File "src/sheltersim/events/effects.py", line 1672, in schedule_effect_program
    "skills": parameters.skills,
AttributeError: 'dict' object has no attribute 'skills'
```

## 再現

#66 のテスト作成中に確認しました（`develop` の `cd419f8`）。

1. 共通fixtureの生成Scenario（20人・6時間）を60分まで進める。
2. 待機中の `staff_002` に `{"skills": ["support", "water_service", "meal_service"]}` を与える `set_staff_role` のEffectProgramで分岐させる。

## 原因（コードで確認済み）

`schedule_effect_program` の `set_staff_role` の分岐が、`parameters` をパラメータのモデル（`_StaffRoleParameters`）として扱っています。しかし、この時点の `parameters` は辞書のままです。ほかの操作では、ここで辞書をモデルに変換しています。

## 関連

- #66：`tests/integration/test_intervention_outcomes.py` に、期待する振る舞いを `xfail(strict=True)` で置いています。直したら印を外してください。
