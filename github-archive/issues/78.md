## 元の本文

## 現象

退所の介入（`depart_evacuees`）は承認され、予定どおりの時刻に処理されます。しかし、イベントが `failed` になり、誰も退所しません。記録される理由は `event payload and provenance must contain finite JSON values` です。

## 再現

#67 のテスト作成中に確認しました（`develop` の `097ea10`）。

1. 共通fixtureの生成Scenario（20人・6時間）を60分まで進める。
2. 寝室の区画から5人を退所させる `depart_evacuees`（`{"count": 5, "include_initial": true}`）で分岐させ、61分へ進める。

## 原因（コードで確認済み）

- 選ばれた人の中に行動中の人がいると、`queue_departures` が退所を後回しにします。その際、`_schedule_departure_retry`（`src/sheltersim/domain/population.py`）で再試行のイベントを作ります。
- このとき、元のイベントのprovenanceをそのまま渡しています。EffectProgram由来のイベントのprovenanceには入れ子の `mappingproxy` があるので、JSONに変換できずに失敗します。

#76（物資の遅延で止まる）と同じ形の不具合です。#76 は止まるのに対し、こちらはイベントの失敗として記録されて先に進みます。

## 影響

画面上は介入が通ったように見えますが、人数は変わりません。

- #67：`tests/integration/test_intervention_outcomes.py` に、期待する振る舞いを `xfail(strict=True)` で置いています。
