## 元の本文

tick の残りを減らします。同じ負荷の並走で `TickEngine.step` は 84.05 秒から 70.47 秒（16% 減）です。負荷のない 60.9 秒に当てはめた短縮は約 7〜10 秒で、目標の 10〜15 秒の下限です。残りは 0.05 ms 未満の変更の積み重ねか状態の所有の移動になるので、ここで止めました。

## 変更
- `WorldState.unsettled_support_requests()`: 終わっていない支援の依頼だけを tick の中で読みます。確定済みの依頼が開き直された、辞書が差し替わった、記憶がない（分岐の直後、`SHELTERSIM_NATIVE=0`）場合は全部を読みます。
- GC の最も若い世代の回収を 50,000 個ごとから 200,000 個ごとに変更します（late 1,500 分の回収時間 1.03 秒から 0.45 秒）。
- view、関係キー、イベント記録の細かい作り直しを減らします（`ordered_pair_key` の `lru_cache` は文字列2つの純粋関数）。

毎 tick の検証に新しい緩和はありません。
