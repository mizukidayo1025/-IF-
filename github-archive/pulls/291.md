## 元の本文

## 概要

5倍高速化の手順の A7（デモの体感）の3つ目です。分岐した子 Branch の最初の保存で、分岐元の Checkpoint の chunk を参照し、書き直さないようにします。

Checkpoint の chunk を pack にまとめる形（#279）では、保存のたびに「前の保存」の目録から chunk の場所を引き継ぎ、同じ chunk は書き直しません。ただ、子 Branch の最初の保存には前の保存がありません。そのため、分岐元とほとんど同じ中身なのに、7日目近くでは約2,700個の chunk を個人情報の検査からやり直し、すべて書き直していました（約6秒）。

## 変更（`storage/projects.py` の `_save_branch`）

新しい子 Branch の最初の保存では、子の Checkpoint の `runtime_state.fork_origin.checkpoint_hash`（分岐元の Checkpoint）の目録から、chunk の場所を引き継ぎます。

- 前の保存がある場合や、同じ Checkpoint がすでに保存されている場合は、今までどおりそちらを使います。
- 引き継いだ chunk は、分岐元の保存のときに検査を通っているので、検査し直しません。これまでも、すでにある chunk は検査し直していませんでした。
