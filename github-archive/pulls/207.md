## 何を直したか

図面の候補抽出（`region/plan_extract.py`の`_rectangular_room_candidates`）で、縦の壁を部屋の左右の境界として数える条件を直しました。

- 前：`overlap_left + 6 <= x <= overlap_right - 6`。縦の壁が、上下の横の壁の端から6px以上**内側**にあることを求めていたため、角で接する外壁は必ず外れていました。
- 後：`overlap_left - 6 <= x <= overlap_right + 6`。端の**外側**へ6pxまでの誤差を許します。上下方向の条件（`top - 6`、`bottom + 6`まで）と同じ向きにそろえました。

合成の図面での部屋の候補の数：

| 図面 | 前 | 後 |
|---|---|---|
| 部屋1つ（外壁だけ） | 0件 | 1件 |
| 仕切り1本（部屋2つ） | 0件 | 2件 |
| 仕切り2本（部屋3つ） | 1件（中央だけ） | 3件 |

仕切りに扉がある避難所の図面（`tests/support/plans.py`）では、仕切りが上下に通っていないため、建物全体が1つの部屋の候補になります。候補はどれも確認待ち・低信頼度のままなので、図面を描く人が除外するか、座標を直します。

## テスト
