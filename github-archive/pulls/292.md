## 概要

5倍高速化の手順の A7（デモの体感）の4つ目です。保存済みの Checkpoint の読み込みを少し速くします。分岐・計算の再開・過去の時刻の参照は、どれもこの読み込みから始まります。7日目近くでは約21秒かかっていて、分岐（約30秒）の大部分でした。

## 変更

- **`ScheduledEvent.from_saved`（`events/models.py`）：** 保存した文書からイベントを作ります。
  - ハッシュを確かめた正規化した JSON から読んだ文書なので、payload と来歴は、有限の値だけの JSON であることが決まっています。そのため、`json.dumps` でもう一度 JSON にして確かめる処理だけを省きます。
  - ID・時刻・種類の確認と、payload の凍結は、今までどおり行います。
  - 項目が揃っていない文書は、今までどおりコンストラクターに渡し、同じ誤りになります。
- **`WorldState.from_dict(..., _saved_json=True)`：** Checkpoint の復元（読み込みと、保存の復元の確認）で、EventLog と待ち行列のイベントを `from_saved` で作ります。それ以外の呼び出しは、今までどおりです。
- **分岐（`TimelineStore.fork`）：** 親を `keep=False` で読み込みます。読んだ世界は子 Branch に渡すので、後の読み取りのための写し（#258）は役に立たず、作るのに約3秒かかっていました。
