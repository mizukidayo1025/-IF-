## 置き換えたテストが見逃さないか

Checkpointから復元した後に状態を壊して、`test_checkpoint_resume` と同じ比較で見つかるかを試しました（テストには入れていない、一時的な確認です）。

- 仮設トイレの図面上の位置（`geometry_overlay_v1` の `facility_points`）を消す → 状態と指標が一致しなくなる
- 通路の使用時間（`edge_usage_minutes`）を消す → 状態が一致しなくなる
- 職員の位置を消す → 検証で例外になる
- 移動中の経路（`journeys`）を消す → 次のtickで実行中のタスクから同じ経路が作り直されるため、一致する。この比較では見つけられないが、保存しなくても結果が変わらない状態なので、不具合ではない
