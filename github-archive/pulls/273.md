## 元の本文

Windows と macOS でも CI でテストを流す準備（#48 の段階3で Windows を対応環境に含めるため）で見つかった、文字コードの不具合を直します。

## 変更
- テキストのファイルの読み書き（`Path.read_text`・`write_text`）で、文字コードを指定していない箇所に `encoding="utf-8"` を付けました。src では、CLI の `--input-json` の読み込みなどです。tests でもあわせて22か所を直しています。
  - 指定しないと、OS の既定の文字コードになります。Windows では cp1252 や cp932 になり、Scenario や保存した JSON の日本語を読み書きできません（`UnicodeEncodeError` / `UnicodeDecodeError`）。
- CLI（`sheltersim …`）は、起動時に標準出力と標準エラーを UTF-8 にします（`reconfigure`）。CLI は日本語を含む JSON を出力するので、Windows でパイプやファイルに書き出すと既定の文字コードでは書けないためです。
- Node.js で画面の JavaScript を動かすテストは、出力を UTF-8 で読みます（`subprocess.run(..., encoding="utf-8")`）。
- `docs/testing.md` に、テキストの読み書きと `subprocess` の文字列の出力で `encoding="utf-8"` を明示する決まりを足しました。
