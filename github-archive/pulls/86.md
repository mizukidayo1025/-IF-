## 変更内容

`tests/integration/test_intervention_outcomes.py` に、環境を変える6種類の介入のテストを6件足しました。#60 の最初のPRと同じ手順です。共通fixtureの本線を分岐させ、避難スペースの環境を60〜300分だけ変え、本線と比べます。

6種類とも、生成Scenarioにそのまま適用でき、期待した向きに結果が変わりました。今回は新しい不具合は見つかっていません。

| 介入 | 設定 | 確かめること |
|---|---|---|
| `set_ambient_noise` | 騒音 1.0 | 疲れの平均が本線より高い |
| `set_lighting` | 明るさ 1.0 | 疲れの平均が本線より高い |
| `set_ventilation` | 換気 0.0 | 衛生の必要度の平均が本線より高い |
| `set_privacy` | プライバシー 0.0 | 不満の平均が本線より高い |
| `set_temperature` | 35℃ | ストレスの平均（KPI）が本線より高い |
| `modify_demand_rate` | 休む（`rest`）の起こりやすさ ×2、続ける時間 ×2 | 休む1回あたりの時間が本線より長く、疲れの平均が低い |

比べ方は次のとおりです。

- 環境の効果は、介入が続いている間に人の状態へ積み上がります。期限が過ぎると差が薄れていくので、期限の300分で比べます。その時点で効果がまだ働いていること（状態に介入の記録が残っていて、期限切れはまだ処理されていないこと）も確かめます。
- 疲れ・衛生の必要度・不満はKPIにないので、全員の平均を直接比べます。
- 行動の起こりやすさは、トイレではなく「休む」で確かめています。この生成Scenarioでは、避難スペースでトイレが選択肢に入る判断が4時間に2回しかなく、トイレの倍率を2倍にしても選ばれる行動が変わらなかったためです。調べた範囲では、倍率は人の判断に届いていました。休みを選べる判断の中で実際に休みを選んだ割合は、本線の約29%に対して約41%でした。
