## 元の本文

PDFレポートの2本の比較で、共通の起点を、比較の frame を作らずに読みます。

## 変更

- `collect_report`（`web/pdf_report.py`）の流れ:
  - 各 branch をレポートの時刻に復元します（`seek`）。
  - そのあと `workspace.comparison()` を呼び、共通の起点（`shared_origin`）だけを使っていました。
- `comparison()` は各 branch の frame を作り直します。保存境界の間の時刻なら、復元と再計算をもう一度行います。
- PR #240 で追加した `comparison_context()`（共通の範囲・分岐の記録・共通の起点を、frame なしで返す）を使うようにしました。範囲外の時刻などを拒否する確認とメッセージは同じです。
