## 元の本文

結果への質問（results chat）で比較の根拠を作るとき、すでに読んだ自分の branch の frame を使い回します。

## 変更

- `ResultsChatService._project_evidence` は、まず質問した branch の frame を読みます。比較する branch があると、そのあと `workspace.comparison()` を呼んでいました。
- `comparison()` は、質問した branch の frame も作り直します。保存境界の間の時刻なら、復元と再計算をもう一度行います。
- 比較は、すでに読んだ frame と、ほかの branch の frame、比較の文脈（PR #240 の `comparison_context`）から組み立てます（`comparison_projection`）。
- 範囲外の時刻などを拒否する確認とメッセージは同じです。
