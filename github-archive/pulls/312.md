## 元の本文

## 変更
- `experiments/runner.py` の段階を `experiments/phases/{dispatch,update,propose,arbitrate,sample,metrics}.py` の mixin に分けました。各段階は名前の付いた手順の並びです。`OfflineSimulationController` の API と属性名は同じです。
- `policies/behavior.py` の `WorldView` と view の型を `policies/world_view.py` に移し、`behavior.py` から再 export します。
- `native/src/contacts.rs` の2つの kernel を `rules/social_propagation.rs`、`rules/information.rs` に移しました。

## 移動だけであることの確認
- `_run_phase` 以外の 23 メソッドと、`behavior.py` の 30 の定義は AST が同じです。Rust の kernel は本文が同じです。
- `_run_phase` はテストが class に patch するので `runner.py` に残し、段階のメソッドへの振り分けにしました。
- 手順の分割の継ぎ目だけ変わりました（`outcomes` などを戻り値で渡す）。
- テストの変更は 1 か所です: `_view_state_hash` の patch 先を `world_view` にしました（再 export の名前に patch すると効かないため）。
- `benchmarks/gate_all_paths.py` の `TICK_SIDE` に `experiments/phases/` を足しました（カバレッジから抜けないように）。
