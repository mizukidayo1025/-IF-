## 原因

眠ることを選んだ人は、仮設の部屋のベッドを予約して歩いていきます。そのあと眠れなかった原因は、2つありました。

1. **到着で待機に戻る**（`events/handlers.py`）：移動の完了の処理が、目的が `sleep_bed` でも活動を「待機（IDLE）」に戻していました。次の判断（15分後）まで眠らず、次の判断でまた眠ることを選んで、もう一度ベッドへ歩く、を繰り返していました。
2. **毎分、区画の中央へ戻される**（`domain/movement.py`）：移動の処理は毎分、移動中でも行列中でもない人を全員、区画の中央に置き直します。眠っている人も対象なので、ベッドに着いても次の分には中央に戻っていました。

## 変更内容

- `sleep_bed` の移動が終わったら、活動を「眠っている（SLEEPING）」にします。
- 眠っている人がベッドを予約していれば、毎分の置き直しでもそのベッドの位置に置きます。
- 次の判断で眠る以外を選んだら、これまでどおりベッドの予約は解放されます。

2つは両方必要です。どちらか一方だけだと、ベッドで眠る人は0のままでした（片方ずつ戻して確認）。

## 結果

生成Scenario（20人）で、避難スペースに4床の部屋を60〜300分に作った場合：

| | 修正前 | 修正後 |
|---|---|---|
| ベッドへの移動（`A019`） | 15分ごとに繰り返す | 眠り始めるときだけ（81分、251分） |
| 61〜299分にベッドで眠った延べ人・分 | 0 | 43 |

眠っている人が次の判断で「ほかの人を手伝う（help_others）」を選ぶと、ベッドの予約は解放されます。ところが、活動は「眠っている」のまま残ります。本線（部屋なし）でも同じで、部屋とは関係なく、もとからある動きです。この PR では変えていません。
