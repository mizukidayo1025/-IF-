## 元の本文

**history index の書き込みキャッシュの大きさを変えるPRです。#221 でチームが決めるまでマージしないでください。** 判断の材料として計測を用意しました。

## 変更

- history index の書き込み用の接続のページキャッシュ（`storage/history_index.py` の `_WRITE_CACHE_KIB`）を、16 MiB から 64 MiB にします。
- #217 でも 64 MiB の方が速いと分かっていましたが、ピークRSSが約55 MiB増えたため、16 MiB にしていました。
