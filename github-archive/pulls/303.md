## 元の本文

計算が速くなったことで、`test_two_runs_compute_at_once_up_to_the_limit` が Linux の CI で失敗するようになりました（#302 の run 41109101469）。

```
assert {'paused', 'running'} == {'running'}
```

30分ぶんの目標では、1つ目の Run が2つ目を投入する前に終わることがあるためです。

## 変更
`3fe2622` と同じやり方にします。
- 同時に動くことの確認: 2つの Run に遠い目標を与え、確認してからキャンセルします。
- 30分ぶんの結果（同じハッシュ、`computed_until`）の比較: 2つとも終わるのを待ってから、別に行います。
