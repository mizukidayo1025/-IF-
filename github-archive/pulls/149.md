## 変更内容

`tests/integration/test_resume_checkpoint_loads.py::test_resume_loads_the_head_checkpoint_once` は、`api.submit()` の直後に `assert loads == []` で「`submit()` は head checkpoint を読まない」ことを確かめています。背景workerがassertより先に計算を始めて checkpoint を読むことがあり、#136 の繰り返し実行で10回中2回失敗していました。

`ProjectAPI` のpoolはworkerが1つなので、`submit()` の前に `threading.Event` を待つだけのtaskを入れてworkerをふさぎます。`assert loads == []` を確かめてからEventを立て、今までどおり `api._pool.submit(lambda: None).result(timeout=60)` で計算の完了を待ちます。assertが失敗しても `finally` でEventを立てるので、`api.close()` で止まりません。

確かめる内容（`submit()` は読まず、workerが1回だけ読んで2回検証する）は変えていません。製品コードは変えていません。
