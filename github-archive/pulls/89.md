## 背景

#60 と #53 を閉じる前に抜け漏れを確かめたところ、EffectProgramの27種のうち、トイレ追加（`add_toilet`）だけ本線と比べるテストがありませんでした。#60 の本文では「#51・#52 で確かめ済み」としていましたが、既存のテスト（`tests/test_installed_facility_announcement.py` の `test_installed_toilets_are_placed_announced_and_used`）が確かめているのは、追加したトイレが置かれ、知らされ、使われることまでです。待ち時間などが本線と比べて変わるかは見ていませんでした。

## 変更内容

`tests/integration/test_intervention_outcomes.py` に1件足しました。

- トイレがすべて使える状態では、20人ではほとんど列ができず、2基足しても待ち時間の差は数分でした。
- そこで、運営者が `toilet_01` の故障（〜300分）を報告した生成Scenarioで、2基を足します。修理のテストと同じ条件で、`REPORTED_TOILET_OUTAGE` として共通にしました。
- 確かめること：
  - 追加した2基が使われる
  - トイレの利用件数が本線より多い（24 → 28件）
  - 平均の待ち時間が本線より短い（35.2 → 28.6分）
  - トイレの緊急度の平均が本線より低い（0.19 → 0.13）

`docs/testing.md` も更新しました。

- テストの地図と集計を更新（統合 229 → 230件、計 937 → 938件）
- 穴の一覧の3番（HTTPから通すe2eがない）を #87 に、6番（図面だけを足したfixtureのテスト）を #88 に向けた。どちらも、地図では #58・#60 で扱うとしていましたが、対応していませんでした。
