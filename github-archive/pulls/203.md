- `integration/test_imported_plan_scenarios.py`（3件）
  - 画像を抽出のラスターの上で手でトレースしたものとGeoJSONのどちらも、承認してScenarioに指定すると開始できる。図面のZone・施設・座標がScenarioに入り、Checkpointから同じ世界に再開できる。
  - 給水と配食が行われる（#201 の`xfail`）。
- `unit/region/test_plan_extract.py`（5件）：壁と扉が確認待ち・低信頼度の候補になる（扉はトレースの扉と同じ位置）。PDFは選んだページから抽出され、ないページは拒否される。部屋の候補（#200 の`xfail`）。
- `unit/web/test_plan_services.py`（72件）：トレースの承認と読み戻し、確認済みの候補から作るGeometry、誤った入力（トレース20種類、要求16種類、GeoJSON30種類、JSONでないアップロード2種類）が理由付き（`StorageError`か`ValueError`）で拒否されること。理由なしで落ちる7種類は #202 の`xfail`。
