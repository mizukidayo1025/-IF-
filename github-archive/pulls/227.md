## 元の本文

イベントの payload を凍結・解凍する処理（`_freeze_json` / `_thaw_json`）で、JSONのスカラー値をすぐに返すようにします。

## 変更

- 2つの関数は、すべての値について `typing.Mapping` との `isinstance` を調べていました。`typing` の別名に対する `isinstance` は遅い経路を通ります。
- 型がちょうど `str`・`int`・`float`・`bool`・`None` の値は、そのまま返します（これまでも、どの分岐にも当たらずそのまま返していた値です）。
- `Mapping` は `collections.abc` から読み込みます。`typing.Mapping` に対する `isinstance` は `collections.abc.Mapping` に委ねられるので、判定は同じです。
- それ以外の値（サブクラスを含む）は、これまでと同じ経路を通ります。
