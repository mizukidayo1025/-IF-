## 概要

EventLog の `detail` に保存されるイベントの文（`EventSuppressed`、`EventApplicationError`）を、Rust が Python と同じ文で自分で出すようにしました。Python の該当箇所 366 か所のうち **155 か所**（このレーンで 147 か所、前のレーンからの 8 か所）です。**残りは 211 か所**です。結果は変わらず、比べた範囲で Python の文との違いは 0 件です。

詳細は `docs/rust-port/lanes/l8-texts-events.md` にあります。

## 作ったもの

- `native/src/core/errors.rs`：`errors::suppressed`、`errors::failed`。作った例外には `_sheltersim_native_outcome` の印を付け、`effects::refused_by_python` は印のある例外を拒否に替えずに通します。型の検査の部品（`int_not_bool`、`exactly_int`、`str_of`、`nonempty_str`、`real_number`、`member_of`、`repr` など）も足しました。
- `benchmarks/rule_shadow/text_check.py`（`SHELTERSIM_TEXT_CHECK=DIR`、pytest では `-p text_check`、`SHELTERSIM_TEXT_CHECK_STRICT=1` で違いを失敗にします）：Rust が文を出すたびに、同じ入力で Python の規則を動かし、例外のクラスと文を比べます。入口は `kernel_first` のフックと dispatch の直接の呼び出しです。世界を変えてから抑止する規則（人口の先送り）は、kernel の前に取った写しの上で比べます。
- `tests/integration/test_event_texts.py`：文を kernel 自身が出したこと（印）、世界が変わらないこと、Python の規則と 1 バイト同じことを確かめます。`Unsupported` を期待していた既存のテストは、意味を保って書き直しました。
- 道具が違いを拾うことは、移した文 2 つを 1 文字ずつ変えて確かめました（テスト 1 件失敗、ゲートの比較で 304 件の違い、ゲートのハッシュが 3 シナリオで変化）。
