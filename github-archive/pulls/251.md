## 元の本文

分岐どうしの最初の違いを探す問い合わせ（`first-divergence`、`mode=world`）で、世界のハッシュを差分で計算します。

## 修正前

- 調べる分ごと・branch ごとに `world.to_dict()`（世界全体の正準JSONを辞書に読み戻したもの）を作り、それをもう一度JSONにしてハッシュをとっていました。
- 1440分の世界では、1つのハッシュに約1.4秒かかります。1ページ（最大20分）×2本で、1分を超えていました。

## 変更

- 各 branch の再生（`iter_worlds`）に、Checkpoint 保存の履歴キャッシュ（#44）を渡します。キャッシュには、再生が復元した Checkpoint の EventLog で初期値を作ります（PR #241）。
- 分ごとのハッシュは、検証（`to_dict()` と同じ）のあと、キャッシュの文書とエンコーダーで計算します。キャッシュが作る正準JSONは、全体を変換した場合とbyte単位で同じなので、ハッシュは `digest(world.to_dict())` と同じです。
- `world` モードは、これまでどおりハッシュだけを返します（標本そのものは返しません）。`kpis`・`person` モードは変えていません。
