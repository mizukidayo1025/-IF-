## 概要

イベントの文以外のエラー文（`ValueError`、契約のエラーなど）を、Rust が Python と同じ文で自分で出すようにしました。担当の 3 つの規則にある Python のエラー 93 か所のうち 88 か所です。比べた範囲で違いは 0 です。結果は変わりません。

範囲の決定（step4-plan 4 節）：Rust で 1 バイト同じ文にするのは、保存されるデータ、`match=` で固定したテスト、有効な入力で届くエラーです。どの入力からも届かない拒否は、手順 4（L10）で検査の名前を含む 1 つの出口にまとめます。そのため、担当範囲の 23 kernel の多くは手を付けていません。

詳細は `docs/rust-port/lanes/l8-texts-rest.md` にあります。

## L8a との合わせ方

- `native/src/core/errors.rs`：マージ済みの L8a のファイルをそのまま使い、このレーンの節を後に足しました。検査には L8a の `exactly_int`、`int_not_bool`、`real_number`、`repr_str` を使います（64 ビットを超える整数は、文を出さずに `Unsupported` になり、少し保守的になりました）。`invariant` と `corrupt` は手順 4 の入口が使うまで `allow(dead_code)` で残します。このレーンのエラーには L8a の印が付かないので、`effects.rs` の `refused_by_python` は従来どおり `Unsupported` に替えて Python が判断します。
- `core/kernels.py`：L8a の `before`/`after` の形に合わせました。フックがすべて `None` のときは、L8a の素の try/except の速い道です。`segments.py` も同じ形です。
- 比較の道具は 2 つ残します。比べるエラーが重ならないためです。L8a の `text_check.py` は保存されるイベントの文、このレーンの `error_compare.py`（`SHELTERSIM_ERROR_COMPARE=DIR`、`SHELTERSIM_ERROR_COMPARE_STRICT=1` で最初の違いを `AssertionError` にします）はこのレーンの出口が作ったエラーを比べ、`segments.py` の手順と driver の `or_rule!` も見ます。

## 数と残り

Rust に足したエラーの出口は 91 か所です。そのうち 66 か所は、Python とクラスと文を比べるテストの中で届きます。届かないのは 25 か所（overlay の占有域、障害物、壁、予約の寝台、凹形の区域の文と、一部の型の組み合わせ）です。道具が違いを拾うことは、3 つの文を 1 文字ずつ変えて確かめました（比較するテスト 5 件が失敗、道具が 3 件の違いを数えて終了コード 1）。

残り：
- 上書きの 4 つの文。Python は ID と行より先に 16 KiB の上限を確かめますが、Rust は ID と行が正しくなってからでないと長さを測れません。
- `shift_windows_by_staff must be an object`
- `resources.rs` の `ResourceLedgerError` 14 か所。拒否の後に Python がたいてい普通に返るので、条件が Python と 1 対 1 になりません。
- 次の候補は `service.rs` 3、`staff.rs` 2、`toilet.rs` 2 です（テストで有効な世界から届きます）。
- 壊れた状態での Python 自身の例外（`KeyError`、`ZeroDivisionError`）は、1 つの出口の候補です。
- 担当のファイルで一度も届かない拒否は約 1,040 か所あり、テストは書いていません。

**壊れた状態の拒否（C 群）：** Run で届く 6 行のうち 4 行はすでに閉じています。残る 2 行（`effects.rs` と `handlers.rs`）は Python が本物の文を出すので E 群で、L8a が扱いました。1 つの出口にまとめたものは 0 か所です。今まとめると Python と比べられず、テストで届く拒否の多くは Python がその後普通に返るので、今エラーにすると Run とテストが止まるためです。

**読んでいて見つけた不一致（変えていません）：** `prepare_independent_facility_queue` は、`requests` に並んだ依頼がないと Policy を作りませんが、Python は作るのでエラーになり得ます。
