## 元の本文

Closes #161

保存したRunのinspectorの地図（`web/inspector.py` の `zone_map`）について、Issueの2つの候補を両方行います。

- 図面のあるRunは、図面から描く。
- 地図に描けない区画にいる人を、黙って外さずに明示する。

Project画面（frameで描く）は変わりません。

## 変更

### 図面から描く（`web/inspector.py`）

Runの `manifest.json` に `model_configs.facility_geometry` があれば、そこから表示用のlayoutを作ります（`_geometry_layout`）。
- メートル単位の図面を、縦横比を保って地図のcanvas（`index.html` の1000×560、余白20）に縮小し、中央に置く。
- 区画の多角形を作る。区画名は `zones.json` から取る。
- 施設の位置は `facility_points` から取る。
- 返す `layout` は同梱の体育館と同じ形で、`id` は `facility-geometry`。`synthetic_layout` は `false`（Runと関係のない合成図ではないため）。

図面のないRunは、今までどおり同梱の体育館で描きます。

図面は `overview()` の manifest ではなく、Runの `manifest.json` から読みます。`overview()` の manifest は表示用に整理されていて、座標（`x`・`y`）が取り除かれているためです（施設の位置もすでにこの方法で読んでいた）。

### 描けない人を明示する（`web/inspector.py`、`static/app.js`）

- 地図に多角形がない区画にいる人を、応答の `undrawn_agents`（Agent IDと区画）に載せる。対象は、体育館にない区画や、介入で増えた区画など。
- 地図の注記に「N人は地図にない区画（food、staff）にいるため非表示」と出す。注記の文は、テストできるように `mapNote(map)` に切り出した。
