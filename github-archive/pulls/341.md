## 元の本文

## 概要

`events/effects.py` のうち tick の中で動く規則を Rust へ移し、`effect_program_v1` を型付きの行で持つようにしました。比較できる範囲で結果は変わりません。

**7 日間の実行には効果のイベントがありません。** 7 日間で比較できるのは、印のないガードと、名前空間がない形の検査だけです。ハンドラー、ガードの式、名前空間がある検査の比較はゲートとテストだけで、ゲートの実行は操作ごとに 1〜16 回です。

このレーンは速度のためではなく、手順 4 で Python の規則を消すためのものです。

詳細は `docs/rust-port/lanes/m6-effects.md` にあります。

## 移した処理

- `native/src/rules/effects.rs`、`native/src/state/effect_program.rs`（設計の `V` の木ではなく型付きの行にし、`step3-design.md` を直しました）
- ガードと 5 つのハンドラー：設備、環境、仮設の部屋、geometry、構造（`add_staff`、`add_toilet`、`set_staff_role`、`facility_repair`、`staff_handoff`、`staff_task_order`）
- `has_active_facility_modifier`、`has_pending_facility_modifier`、`validate_effect_program_state`（tick と履歴の両方）

ハンドラーの「コピーして、変えて、検証して、差し替える」形は、手順 3 の設計どおり残しました。成功以外はすべて、世界を変えずに `Unsupported` を返し、Python の規則が文を作ります。`validate_effect_program`、`schedule_effect_program`、pydantic の契約は変えていません。実行時は Rust が同じ箇所で `model_validate` を呼びます。

## 分かっている弱点

- 操作ごとの比較は少なく、入力はファジングしていません（決まった悪い例だけ）。`staff_handoff` の成功の比較はゲートの 1 回だけで、テストは拒否だけを見ます。
- 感度：結果が検証で弾かれる誤り（設備の units +1、環境の `start_minute` +1）は、Python に戻るのでハッシュは通ります。シャドーの「Python が適用したものを拒否した」の差とテストで検出します。`staff_handoff` の `busy_until` +1 は**シャドーだけ**が検出し、テストはありません。職員の上限 100→101、ガードの節の上限 20→21 はテストだけが検出します。
- ほかのモジュールの関数を Rust から名前で呼びます。名前や引数が変わると kernel は Python に戻ってハッシュは通るので、シャドーか `effects.stats()` の拒否の数でしか分かりません。
- ガードは実体の行を読むので、`facility.__dict__` への直接の書き込みは見えません。
- `check_state` は `with_row` の中で Python（`EventsById`、設備の読み取り）を呼びます。読むだけで mirror に触らないという論証で、テストはしていません。
- Linux 以外は CI に任せます。新しい C API はありません。

## 残り（Python）

`schedule_effect_program`、`validate_effect_program`、pydantic の契約、抑止と失敗の文、コピー・検証・差し替えの手順、ほかのモジュールから名前で呼ぶ規則（`apply_geometry_change`、`place_installed_facility`、`register_temporary_space`、`expire_temporary_space`、`make_*_record`、`order_staff_operation` など）。印のあるイベントは、Rust の表ではなく Python の `dispatch_one` を通ります。

## モデル担当の確認事項

新しい係数も小数の計算もありません。Python と Rust の両方に持つようになった判断の規則は次のとおりです。

- ガードの比較と読む項目、基準と modifier の積み重ねの最小値
- 職員の上限 100、設備の上限 200、追加する職員とトイレの既定値、引き継ぎと修理の条件
- 演算子とイベントの種類の表（テストで Python と比較）
- Rust だけの拒否（Python が動きます）：小数と比べる 2^53 を超える整数、i64 を超える整数、型が完全に一致しない値、`ScheduledEvent` でないイベント、`source_id` のない仮設の部屋のイベント、taint した行
