## 元の本文

#138 の最後の PR です。テストファイルに散らばっていた `fixtures/` のパスの定数を、`tests/support/paths.py` の1か所にまとめます。相談のとおり、テストファイルから import してよいのは `support.paths` の定数だけです。この PR で #138 の完了の条件をすべて満たします。

## 変更

### `tests/support/paths.py`

テストが使う `fixtures/` のファイルの定数を足しました。

- `FIXTURES`、`SCENARIOS`
- `SCENARIO_100_AGENTS`、`SMALL_REPLAY`、`BASELINE_100_7D`、`FAILURE_DAY3`、`RESEARCH_OPERATIONAL_100_7D`
- `REGRESSION_CONTRACT`、`SOURCE_MANIFEST`、`AGENTS_INITIAL`、`PROFILES_SMALL`、`GYM_LAYOUT`、`DEMO_REPLAY`

Scenario に限らず、`fixtures/` のファイル全体を同じ決まりで扱います。

### テストファイル（69本）

- **module 単位の定数**：約60本が、`Path(__file__).parents[N] / "fixtures" / ...` から自分の定数を作っていました（`FIXTURE`、`SMALL_SCENARIO`、`BASELINE_PATH` など、同じファイルに違う名前がついていた）。
  - 定数の値を評価し、指す実際のファイルで `support.paths` の名前に対応づけた。
  - 使っている箇所の名前を置き換え、定義を消して import を足した。
  - 置き換えは ast で位置を求めた箇所だけなので、文字列は変わらない。
- **作業ディレクトリに頼る相対パス**：`ScenarioSpec.load("fixtures/scenario_100_agents.json")` のような書き方も、定数に置き換えました。リポジトリの外から pytest を実行しても、同じファイルを読みます。
- **関数の中の `Path(__file__).parents[N] / "fixtures" / ...` と `ROOT / "fixtures" / ...`**：同じく定数にしました。
  - 1本だけで使う評価用のファイルは、`FIXTURES / "evaluation" / ...` にした。
  - 使われなくなった `ROOT` は消した。`src/` を指す `ROOT` は残している。
- **残したもの**
  - 1本のファイルだけで導くパス（`RUNS = DEMO_REPLAY / "runs"` など）は、そのファイルに残した。
  - `test_provenance.py` と `test_source_manifest.py` の `"fixtures/..."` は、台帳の文字列と比べるデータなので変えていない。

これで、`fixtures/` を `parents[N]` から組み立てるのは `support/paths.py` だけです。

### `docs/testing.md`

「テストの置き場所と名前」に例外を書きました。`fixtures/` のパスは `from support.paths import …` で使い、テストファイルの中で組み立てません。`support/paths.py` の説明も直しています。
