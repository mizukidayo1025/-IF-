## 分かっている弱点

- 作った入力で Rust が Python に揃った例：明示の `None` の人口のオプション、`None` の人口の名前空間、作った移動の経路は、以前は Rust で成功し Python では失敗しました。今は Python の文で失敗します。有効な介入はこれらを送りません。
- effects の規則は世界を写す前に確かめますが、Python は写してから確かめます。`from_dict` や `validate()` に失敗する世界では、`StateInvariantError` ではなくハンドラーの文になります。そのような世界は dispatch の時点ですでに不正です。
- dispatch のガードの数はゲートで測っていません。
- Linux 以外は CI に任せます。
