- 一時外出は、まだ給水・配食を使っていない人を選べば成功します。そこで、その場合を通常のテストにし、使ったことのある人の場合を xfail にしました。

## 見つけた問題（別のIssue）
- **#78 退所の介入が、行動中の人がいると実行時に失敗し、誰も退所しない**：行動中の人の退所は後回しになります。その再試行イベントが、元のprovenance（入れ子の `mappingproxy`）を引き継いでJSONにできず失敗します。#76 と同じ形の不具合です。
- **#79 一時外出などが、給水・配食を利用したことのある人には失敗する**：外出すると `world.agents` から外れますが、給水・配食の依頼履歴にはその人が残ります。そのため、状態の検証で不正と判定されます。
- **#80 仮設スペースを足す介入が、生成Scenarioには適用できない**：必要な状態は `simulator_extensions.enabled` のときだけ作られ、生成Scenarioはこの設定を入れません。#65 と同じく、生成Scenarioに介入用の状態がない例です。
