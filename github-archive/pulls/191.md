## 元の本文

近接接触のモデルを選ぶと、ProjectのRunが最初のCheckpointの保存で止まる不具合を直します。係数とモデルの署名は変えていません。

## 原因

近接接触のモデルの署名は `distance-sampled-proximity-v1@1:state1:distance=1.5:interval=15:pairs=500` です。メールアドレスの検出 `\b[^\s@]+@[^\s@]+\.[^\s@]+\b` は、「@」のあとに「.」があれば一致します。そのため、`1.5` の小数点でメールアドレスとみなされていました。

この検出は3か所にコピーされていて、影響がそれぞれ違いました。

| 場所 | 用途 | 影響 |
|---|---|---|
| `storage/projects.py`（`_SECRET`） | Checkpointの保存の内容検査 | 伏せ字になった値はもとと違うため、**保存を拒否して止まる** |
| `inspection/traces.py` | Run成果物 | manifest の署名が `[REDACTED]` になる |
| `web/inspector.py` | 保存したRunの表示 | 署名を含む表示が伏せ字になる |

## 変更

- `storage/projects.py`：メールアドレスの検出を、公開の定数 `EMAIL_ADDRESS` として1つだけ定義した。ドメインの末尾（TLD）を、文字（Unicodeの文字を含む）2文字以上に限る（`\b[^\s@]+@[^\s@]+\.[^\W\d_]{2,}\b`）。`_SECRET` はこれを使う。
- `inspection/traces.py`、`web/inspector.py`：自分のコピーを消し、`EMAIL_ADDRESS` を使う。

確かめた例は次のとおりです。

| 値 | 直す前 | 直した後 |
|---|---|---|
| 近接接触のモデルの署名 | 伏せ字 | そのまま |
| `name@example.com`、`name@example.invalid` | 伏せ字 | 伏せ字 |
| `a.b+c@mail.example.co.jp` | 伏せ字 | 伏せ字 |
| `user@例え.テスト`（国際化ドメイン） | 伏せ字 | 伏せ字 |
